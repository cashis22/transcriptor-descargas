# Transcriptor de Reuniones

Descargas y actualizaciones del Transcriptor, un programa de escritorio que
convierte grabaciones de reuniones y clases en texto. Todo el procesamiento
ocurre en la propia computadora: el audio no sale de la máquina.

## Descargar

En **[Releases](../../releases/latest)**:

| Archivo | Peso | Cuándo |
|---|---|---|
| `Instalar-Transcriptor.exe` | ~13 MB | Lo normal. Descarga solo lo que le falta la primera vez que se abre. |

Una vez instalado, el programa avisa cuando hay una versión nueva y se
actualiza con un clic.

## Requisitos

Windows 10 u 11. Nada más: el motor de transcripción y el idioma se descargan
desde el propio programa.
